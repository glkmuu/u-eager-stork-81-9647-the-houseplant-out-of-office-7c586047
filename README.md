# The Houseplant Out-of-Office

This entry is a one-line out-of-office auto-reply written as if a neglected houseplant sent it: the fern announces it is out of office, admits nobody has watered it in months, and reports that your email has been composted. The joke is the plant's own life doing the work — months of being ignored, then the inbox itself turned into fertilizer — kept tight in a single 92-character line, well inside the competition's 120-character limit.

## Running it

```sh
python3 main.py
```

This validates the entry (UTF-8, 1–120 characters, exactly one line, not only whitespace), writes it to `/output/entry.txt` for grading and to `entry.txt` beside the script, and verifies both files byte-for-byte after writing. Stdlib only, no dependencies, no network.
